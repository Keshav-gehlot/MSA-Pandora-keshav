# Prompt: help me understand something

Use any time: a file you didn't write, a concept, an error, or the diff your agent just produced.

```
Explain <file path / function / concept / this diff> in MSA Pandora to me. Assume I'm new to <the technology>.
Cover: what it does, why it exists in this project (which flow or package uses it), how data moves through it,
and one thing that would break if it were removed or done differently. Point me to the docs/tech/ note if there is
one. Then ask me two questions to check I understood.
```
